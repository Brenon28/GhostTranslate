# GhostTranslate

Оверлей для Windows: выделяете область на любом мониторе или весь экран под курсором, программа читает английский текст и рисует перевод поверх. Версия 3.2. Код приложения лежит в пакете `ghosttranslate/`, а `main.py` только запускает его.

На каждом мониторе своё прозрачное окно перевода, оно пропускает мышь. Панель, журнал и настройка шрифта остаются обычными окнами поверх остальных. Все эти окна исключены из снимка экрана, поэтому OCR не читает собственные подписи программы.

## Установка для обычного запуска

Скачайте `GhostTranslate_v3.0_Setup.exe` со страницы [Releases](https://github.com/Brenon28/GhostTranslate/releases), запустите его и откройте GhostTranslate из меню Пуск. Python ставить не нужно: библиотеки и модель перевода уже внутри.

Нужны Windows 10 или 11, 64-bit, и английский языковой пакет распознавания текста: Параметры, Время и язык, Английский, Распознавание текста. Установщик и сама программа запрашивают права администратора, иначе глобальные клавиши F8 и F9 не работают поверх других окон.

Дальше в этом файле описан запуск из исходников. Он нужен для разработки, не для обычной установки.

## Что нужно для запуска из исходников

- Windows 10 или 11, 64-bit
- Python 3.12, 64-bit
- Языковой пакет английского OCR в Windows. Параметры, Время и язык, Язык и регион, Английский, Языковые параметры, Распознавание текста
- Для перевода поверх полноэкранной игры процесс лучше запускать от администратора. На рабочем столе хватает обычного пользователя

## Библиотеки

Обязательные, файл `requirements.txt`:

| Пакет | Зачем |
|---|---|
| PyQt6 | Панель, оверлей, настройка шрифта |
| numpy | Сравнение кадров и цвет фона плашки |
| mss | Снимок области экрана |
| Pillow | Картинка для Windows OCR |
| pywin32 | Прозрачность окна и клики сквозь оверлей |
| ctranslate2 | Перевод EN-RU на CPU, формат int8, без PyTorch |
| sentencepiece | Токенизатор той же модели |
| winocr | Системный OCR Windows, основной распознаватель |

Необязательные, файл `requirements-dev.txt`:

| Пакет | Зачем |
|---|---|
| rapidocr-onnxruntime | Второй OCR, если Windows OCR недоступен |
| pyinstaller | Сборка `GhostTranslate.exe` |

PyTorch, Argos Translate, Stanza и OpenCV программа не использует.

## Установка и проверка

В корне репозитория:

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```

Либо дважды щёлкнуть `run_ghost.bat`: он берёт `.venv\Scripts\python.exe`, если окружение уже есть.

На этой машине окружение уже собрано: `.venv` в корне репозитория. Модель подключена папкой `model_en_ru` рядом с `main.py`. Оба пути в `.gitignore`.

## Как проверить

1. Запустить `run_ghost.bat` или `python main.py`. Сверху по центру появляется панель и звучит короткий мягкий звон.
2. Нажать «Весь экран» на английском тексте обычного окна. Поверх текста появляются плашки перевода.
3. Нажать F9, зажать левую кнопку и выделить область в пределах одного монитора. После отпускания кнопки эта область уходит в перевод. Пока экран затемнён, клики не доходят до окна под ним.
4. F8 прячет панель и плашки и оставляет у правого верхнего угла метку `GT [F8]`. Повторное F8 возвращает всё обратно.
5. «Aa Шрифт» меняет гарнитуру, масштаб 60-180% или фиксированный кегль, жирность и рамку области, включает и выключает звук и задаёт свои клавиши вместо F8 и F9. Всё это пишется в `settings.json`.
6. Список «Ручной / 0.5s / ...» включает повторный снимок. «Стоп» выключает его и очищает плашки.
7. «Логи» показывает время OCR и перевода.
8. Панель перетаскивается за свободное место или заголовок и остаётся там после перезапуска. Двойной щелчок возвращает её в центр основного экрана.

Пока модель грузится, известные пункты меню берутся из встроенного словаря. Остальной текст сначала остаётся английским и переводится заново, как только ядро готово. В кэш такие строки не попадают.

Если в Windows установлен русский пакет распознавания текста (он ставится вместе с русским языком системы), рядом с английским OCR параллельно работает русский. Английский распознаватель читает русские надписи латиницей («Папка» превращается в «nanKa»), и без второго прочтения такой мусор уходил в перевод. Каждое слово сравнивается в двух прочтениях по словарю модели перевода, русское отбрасывается. Это добавляет около 20 мс к распознаванию.

Автотесты разметки, координат мониторов, клавиш, панели и конвейера:

```bat
.venv\Scripts\python.exe -m unittest discover -s tests
```

## Клавиши и кнопки

- F8: скрыть или показать оверлей и панель
- F9: режим выделения области, дальше обычная левая кнопка мыши. Esc или правая кнопка отменяют выделение
- Обе клавиши меняются в «Aa Шрифт»: щёлкнуть поле и нажать сочетание. Подходят F1-F12 или сочетания с Ctrl, Alt или Win. Пока программа запущена, Windows отдаёт выбранное сочетание только ей, поэтому для игр, где F8 или F9 заняты, удобнее, например, Ctrl+Alt+T
- «Весь экран»: перевод монитора, на котором открыто активное окно, то есть игра или браузер, а не сама панель. Если такого окна нет, берётся монитор под курсором
- «OCR: WinOCR»: переключение на RapidOCR, если тот установлен
- Шесть стилей плашек: градиент, одна строка, контур, тёмное стекло, неон, высокий контраст
- «Игровой режим» в «Aa Шрифт»: для игр с античитом, подробности ниже
- Повторный запуск не открывает вторую копию: уже работающая программа показывает панель, даже если она была скрыта по F8. Установщик просит закрыть программу перед обновлением или удалением

## Куда ставится модель

Полный перевод ищет каталог, в котором одновременно есть `model.bin` и `sentencepiece.model`. Ожидаемая раскладка рядом с `main.py` или с `GhostTranslate.exe`:

```text
model_en_ru/
  sentencepiece.model
  model/
    config.json
    model.bin
    shared_vocabulary.json
```

`model.bin` около 204 МБ. В git его нет: GitHub не принимает файл больше 100 МБ.

Порядок поиска:

1. `model_en_ru` рядом со скриптом или exe.
2. Распакованный пакет в `%USERPROFILE%\.local\share\argos-translate\packages`, если в имени папки есть `en_ru`.
3. Архив `*en_ru*.argosmodel` или `*en_ru*.zip` в папке программы или в `%USERPROFILE%\.local\share\argos-translate\downloads`. Архив распаковывается в `model_en_ru`.

Если ничего не найдено, работает только словарь игровых меню, примерно 160 фраз. Нейросеть при этом не запускается.

## Игры с античитом

GhostTranslate не читает и не меняет память игры, не встраивается в её процесс и не нажимает клавиши. Он делает снимки экрана и рисует поверх него прозрачное окно.

Обычно окна программы скрыты от захвата экрана флагом `WDA_EXCLUDEFROMCAPTURE`, чтобы OCR не читал собственные плашки. Окно поверх игры с таким флагом похоже на оверлей чита, и античиты умеют такие окна находить. «Игровой режим» этот флаг снимает:

- перед каждым снимком плашки гаснут примерно на 0.1 с, в автоматическом режиме это заметно как мигание;
- панель и настройки на снимке закрашиваются, поэтому не переводятся;
- watchdog под плашками отключается, смену экрана замечает только таймер;
- плашки видны в OBS, на скриншотах и при показе экрана.

Гарантии, что античит не отреагирует, нет. Безопаснее всего переводить меню и тексты вне рейтинговых матчей и держать игру в оконном режиме без рамки: в эксклюзивном полноэкранном режиме оверлей не виден.

## Сборка exe

Нужен `requirements-dev.txt` и отдельно Inno Setup 6.

```bat
.venv\Scripts\activate
pip install -r requirements-dev.txt
build_exe.bat
```

`build_exe.bat` собирает `dist\GhostTranslate\` и копирует туда `model_en_ru`, если папка есть. `installer.iss` пакует этот каталог в установщик. `build\`, `dist\` и `installer_out\` в git не входят.

## Ограничения

- Перевод идёт на одном мониторе за раз, рамка F9 не выходит за край монитора, где её начали.
- Мониторы с разным масштабом (100%, 125%, 150%) поддерживаются. При подключении, отключении или смене разрешения окна перестраиваются, а выбранная область сбрасывается на весь основной экран.
- Панель в один ряд занимает около 1000 логических пикселей. На более узком экране, например 1280x800 при 150%, кнопки переносятся во второй ряд.
- За один снимок переводится до 150 блоков: первые 16 появляются сразу, остальные следом. На экране с сотнями строк, например в редакторе кода, остаются самые крупные.
- В автоматическом режиме watchdog раз в 150 мс сравнивает картинку под плашками с кадром перевода. Он работает в отдельном потоке и снимает только прямоугольник вокруг плашек.
- Английское слово внутри русской фразы считается частью русского текста и не переводится.
- Кадр для WinOCR увеличивается в 1.5 раза: иначе на мелком тексте сайтов (10-13 px) пропадают целые слова. Это добавляет около 0.2 с на экран 3440x1440.
- Перевод рисуется кеглем оригинала и не мельче 12 px. Если русский текст длиннее английского, плашка абзаца растёт вниз, а плашки ниже сдвигаются под неё. Подпись в одну строку сначала занимает свободное место справа.
- Ники, сабреддиты, ссылки и имена вроде `r/Battlefield6` или `T4Abyss` не переводятся. «35m ago» и «471 upvotes» переводятся шаблоном, без модели.
- Поверх игры глобальные клавиши надёжнее от администратора.
- `settings.json`, журналы и `ghost_report_bundle.txt` при запуске из исходников лежат в корне проекта, у установленной программы — в `%LOCALAPPDATA%\GhostTranslate`. Старый `settings.json` из папки программы переносится туда при первом запуске. В репозиторий эти файлы не коммитятся.
