# GhostTranslate

Оверлей для Windows: выделяете область экрана или весь основной монитор, программа читает английский текст и рисует перевод поверх. Версия 3.0. Весь код приложения в `main.py`.

Окно перевода прозрачное и пропускает мышь. Панель, журнал и настройка шрифта остаются обычными окнами поверх остальных.

## Установка для обычного запуска

Скачайте `GhostTranslate_v3.0_Setup.exe` со страницы [Releases](https://github.com/Brenon28/GhostTranslate/releases), запустите его и откройте GhostTranslate из меню Пуск. Python ставить не нужно: библиотеки и модель перевода уже внутри.

Нужны Windows 10 или 11, 64-bit, и английский языковой пакет распознавания текста: Параметры, Время и язык, Английский, Распознавание текста. Установщик и сама программа запрашивают права администратора, иначе глобальные клавиши F8 и F9 не работают поверх других окон.

Дальше в этом файле описан запуск из исходников. Он нужен для разработки, не для обычной установки.

## Что нужно для запуска из исходников

- Windows 10 или 11, 64-bit
- Python 3.12, 64-bit
- Языковой пакет английского OCR в Windows. Параметры, Время и язык, Язык и регион, Английский, Языковые параметры, Распознавание текста
- Для перевода поверх полноэкранной игры процесс лучше запускать от администратора. На рабочем столе хватает обычного пользователя

## Библиотеки

Обязательные, файл `requirements.txt`:

| Пакет | Зачем |
|---|---|
| PyQt6 | Панель, оверлей, настройка шрифта |
| numpy | Сравнение кадров и цвет фона плашки |
| mss | Снимок области экрана |
| Pillow | Картинка для Windows OCR |
| pywin32 | Прозрачность окна и клики сквозь оверлей |
| ctranslate2 | Перевод EN-RU на CPU, формат int8, без PyTorch |
| sentencepiece | Токенизатор той же модели |
| winocr | Системный OCR Windows, основной распознаватель |

Необязательные, файл `requirements-dev.txt`:

| Пакет | Зачем |
|---|---|
| rapidocr-onnxruntime | Второй OCR, если Windows OCR недоступен |
| pyinstaller | Сборка `GhostTranslate.exe` |

PyTorch, Argos Translate, Stanza и OpenCV программа не использует.

## Установка и проверка

В корне репозитория:

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```

Либо дважды щёлкнуть `run_ghost.bat`: он берёт `.venv\Scripts\python.exe`, если окружение уже есть.

На этой машине окружение уже собрано: `.venv` в корне репозитория. Модель подключена папкой `model_en_ru` рядом с `main.py`. Оба пути в `.gitignore`.

## Как проверить

1. Запустить `run_ghost.bat` или `python main.py`. Сверху по центру появляется панель.
2. Нажать «Весь экран» на английском тексте обычного окна. Поверх текста появляются плашки перевода.
3. Нажать F9, зажать левую кнопку и выделить область. После отпускания кнопки эта область уходит в перевод.
4. F8 прячет панель и плашки и оставляет у правого верхнего угла метку `GT [F8]`. Повторное F8 возвращает всё обратно.
5. «Aa Шрифт» меняет гарнитуру, масштаб 60-180% или фиксированный кегль, жирность и рамку области. Это пишется в `settings.json`.
6. Список «Ручной / 0.5s / ...» включает повторный снимок. «Стоп» выключает его и очищает плашки.
7. «Логи» показывает время OCR и перевода.

Пока модель грузится, известные пункты меню берутся из встроенного словаря. Остальной текст сначала остаётся английским и заменяется переводом, когда ядро готово.

## Клавиши и кнопки

- F8: скрыть или показать оверлей и панель
- F9: режим выделения области, дальше обычная левая кнопка мыши. Esc отменяет выделение
- «Весь экран»: перевод основного монитора
- «OCR: WinOCR»: переключение на RapidOCR, если тот установлен
- Шесть стилей плашек: градиент, одна строка, контур, тёмное стекло, неон, высокий контраст

## Куда ставится модель

Полный перевод ищет каталог, в котором одновременно есть `model.bin` и `sentencepiece.model`. Ожидаемая раскладка рядом с `main.py` или с `GhostTranslate.exe`:

```text
model_en_ru/
  sentencepiece.model
  model/
    config.json
    model.bin
    shared_vocabulary.json
```

`model.bin` около 204 МБ. В git его нет: GitHub не принимает файл больше 100 МБ.

Порядок поиска:

1. `model_en_ru` рядом со скриптом или exe.
2. Распакованный пакет в `%USERPROFILE%\.local\share\argos-translate\packages`, если в имени папки есть `en_ru`.
3. Архив `*en_ru*.argosmodel` или `*en_ru*.zip` в папке программы или в `%USERPROFILE%\.local\share\argos-translate\downloads`. Архив распаковывается в `model_en_ru`.

Если ничего не найдено, работает только словарь игровых меню, примерно 160 фраз. Нейросеть при этом не запускается.

## Сборка exe

Нужен `requirements-dev.txt` и отдельно Inno Setup 6.

```bat
.venv\Scripts\activate
pip install -r requirements-dev.txt
build_exe.bat
```

`build_exe.bat` собирает `dist\GhostTranslate\` и копирует туда `model_en_ru`, если папка есть. `installer.iss` пакует этот каталог в установщик. `build\`, `dist\` и `installer_out\` в git не входят.

## Ограничения

- Оверлей покрывает основной монитор. Область на втором экране в плашки не попадает.
- Поверх игры глобальные F8 и F9 надёжнее от администратора.
- Словарь и нейросеть не защищены от одновременной правки из двух потоков на всём кэше фраз. Сам вызов перевода сериализован.
- `settings.json`, журналы и `ghost_report_bundle.txt` создаются рядом с программой и в репозиторий не коммитятся.
